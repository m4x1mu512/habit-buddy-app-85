# План: Android-приложение «Мои привычки»

## Что получится
Мобильное приложение на русском языке: список привычек, архив, настройки, ежедневные локальные напоминания, светлая/тёмная/системная тема с цветом строки состояния. Всё хранится на устройстве, без сервера и входа. Проект собирается в APK и AAB через GitHub Actions.

## Экраны
- **Привычки**: заголовок, кнопка «Добавить привычку», карточки (название, описание, время, даты, «Бессрочно», статус напоминаний значком и текстом, кнопки «Редактировать» и «В архив»), сортировка по времени, пустое состояние «У вас пока нет привычек» + «Создать первую привычку».
- **Форма (нижняя панель)**: название*, описание, время*, дата начала (сегодня), срок «Бессрочно / До определённой даты», дата окончания (только во втором случае), переключатель «Напоминания включены», «Сохранить» / «Отмена». Проверки: нет названия, нет времени, окончание раньше начала.
- **Архив**: карточки с периодом и причиной («Перемещено пользователем» / «Срок действия завершён»), «Восстановить», «Удалить» с подтверждением «Удалить привычку без возможности восстановления?». Если срок истёк — предложение сначала изменить дату окончания. Пусто — «Архив пуст».
- **Настройки**: тема (Системная по умолчанию / Светлая / Тёмная), статус разрешения на уведомления, кнопка «Открыть настройки приложения» и запасная инструкция для ручного перехода.
- Нижняя навигация «Привычки / Архив / Настройки», учёт системных отступов Android, кнопка «Назад» закрывает панель/диалог, затем возвращает на «Привычки», затем выходит.

## Поведение
- При запуске: загрузка, демо-привычка «Выпить стакан воды» 09:00 (бессрочно, без напоминаний) при пустом хранилище, автоархивация привычек с истёкшим сроком с отменой уведомлений.
- Уведомления: запрос разрешения, ежедневное повторение, заголовок = название, текст = описание; перепланирование при редактировании, отмена при архивации/удалении, создание при восстановлении. Если дата окончания задана — уведомления планируются по дням до неё (ограничено разумным окном и обновляется при каждом запуске), чтобы не было напоминаний после окончания.
- Все сообщения-тосты на русском: сохранено, изменено, в архиве, восстановлено, ошибки сохранения/уведомлений, отказ в разрешении.
- Тема: светлая — строка состояния #111827 со светлыми значками; тёмная — #FFFFFF с тёмными значками; обновление meta theme-color и дублирующая верхняя полоса того же цвета на случай, если система не даёт перекрасить строку.

## Сборка и документация
- npm-скрипты: dev, build, preview, cap:sync, android:open, android:build.
- `capacitor.config.ts`: appId com.example.myhabits (вынесен в одну константу + отмечен в README), appName «Мои привычки», webDir dist, настройки StatusBar и LocalNotifications.
- Папка `android/` с Gradle Wrapper, иконкой уведомлений и разрешениями (POST_NOTIFICATIONS, SCHEDULE_EXACT_ALARM, RECEIVE_BOOT_COMPLETED).
- Подпись release через `keystore.properties`/переменные окружения; без секретов — release собирается без подписи или пропускается, debug APK собирается всегда.
- `.github/workflows/build-android.yml`: workflow_dispatch, push в main, release; Node 20, Java 17 (21, если потребует AGP), npm ci → build → cap sync → assembleDebug → bundleRelease (+ assembleRelease); артефакты my-habits-debug-apk, my-habits-release-apk, my-habits-release-aab; декодирование ANDROID_KEYSTORE_BASE64 только при наличии секретов.
- README на русском: установка, Capacitor, открытие в Android Studio, запуск на устройстве, запуск Actions, где скачать APK, настройка подписи, разница APK и AAB.

## Технические детали
- Проект уже на React + TS + Vite + Tailwind (TanStack Start). Переключаю его в режим статического SPA-приложения (без серверного рендеринга), а сборку дополняю шагом, кладущим готовые файлы в `dist/` с `index.html`, — это то, что требует Capacitor.
- Хранилище: `@capacitor/preferences` (на вебе он сам падает на localStorage). Модель Habit — ровно по ТЗ (id, title, description, reminderTime, startDate, endDate|null, remindersEnabled, notificationId|null, status, archivedReason|null, createdAt, updatedAt); для привычек с датой окончания храню также список запланированных id.
- Модули: `lib/storage`, `lib/notifications`, `lib/theme`, `lib/habits` (чистая логика: валидация, сортировка, автоархивация) + тесты vitest для правил (дата окончания, автоархив, сортировка, демо-данные).
- Кнопка «Назад» — `@capacitor/app` (добавлю зависимость); переход в настройки приложения — Android-intent через небольшой нативный плагин в `MainActivity`, с запасной инструкцией.
- Ограничение проверки: в этой среде нет Android SDK, поэтому `npm run build`, `cap sync` и тесты проверю здесь, а сборку APK — по коду workflow; реальную сборку подтвердит первый запуск GitHub Actions.
